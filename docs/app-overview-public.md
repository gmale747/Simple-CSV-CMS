## How it works
This site is a lightweight static CMS that stores article content in a CSV file and renders it as HTML pages. Visitors can browse a summary page of all posts and open individual article pages for detailed information. The site is designed to be simple, fast, and easy to deploy with static hosting while keeping content updates in a structured, editable CSV file. It provides public information about road conditions, detours, and work-zone guidance through a straightforward content model.

## What this app does
- Publishes public-facing help articles related to road construction and detours
- Stores content in a CSV-based content source for simple updates
- Supports browsing topic summaries and individual article pages
- Runs as a static site for easy deployment and maintenance
